# GeoWorld & LiveGeo

Project homepage for **LiveGeo: Benchmarking Geographic Agents in Continuously Evolving Worlds**.

The website introduces the GeoWorld simulator, the LiveGeo benchmark, main-text findings, and recorded agent cases. It includes the narrated project overview.

This is a buildless static site. Serve this directory with any static HTTP server to preview it locally. For GitHub Pages, use the `main` branch and the repository root (`/`).
